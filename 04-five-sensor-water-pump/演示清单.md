# 仓储安全检测系统 · 功能演示清单

> 硬件：STM32F103C8T6  |  操作：K1=翻页/下移  K2=确认/切换  |  掉电保存：去 SECURITY→SAVE


## 一、首页总览（上电即显示）

```
温度XX℃  湿度XX%         ← DHT11 温湿度
烟雾XXXX  W:XXXX         ← 烟雾/水浸 ADC
H:1 D:1 AUTO OK          ← 人体/门/模式/报警
F:1 P:1 L:1 B:1          ← 风扇/水泵/灯/蜂鸣器
```

| # | 操作 | 预期 |
|---|------|------|
| 1 | 上电 | OLED 亮，AUTO 模式，OK 无报警 |
| 2 | 手指捏 DHT11 | 温度上升 |
| 3 | 打火机气（不点火）靠烟雾传感器 | 烟雾 ADC 值变大 |
| 4 | 水沾水浸传感器 | W: 值变大 |
| 5 | 手晃人体红外 | H: 变 1，撤防时 L: 绿灯亮 |


## 二、自动联动（AUTO 模式）

| # | 触发条件 | 预期动作 |
|---|---------|---------|
| 6 | 有人（撤防状态） | 绿灯自动亮，人走灭 |
| 7 | 烟雾超阈值 | 风扇自动转 + 红灯亮 |
| 8 | 漏水超阈值 | 水泵自动抽 + 红灯 + 蜂鸣器 |
| 9 | 烟雾达火灾等级 | 红灯 + 蜂鸣器 |
| 10 | 温度 ≥ 50°C | 仅红灯亮（无蜂鸣） |


## 三、布防 / 入侵报警

| # | 操作 | 预期 |
|---|------|------|
| 11 | K1翻到 SECURITY → ARM → K2 | 舵机关门，首页显示 ARM |
| 12 | 布防后手晃人体红外 | 红灯 + 蜂鸣器响（入侵报警） |
| 13 | SECURITY → DISARM → K2 | 舵机开门，报警解除，恢复照明 |
| 14 | SECURITY → SAVE → K2 | 保存到 Flash，跳回首页 |


## 四、手动控制（新增）

| # | 操作 | 预期 |
|---|------|------|
| 15 | 首页按 K2 → 进入 MANUAL 页 | 显示 MANUAL (AUTO) |
| 16 | 光标移到 MODE → K2 | 切为 MANUAL (MANU) |
| 17 | 光标移到 FAN → K2 | 风扇开，首页 F:1 |
| 18 | PUMP → K2 | 水泵开 |
| 19 | LIGHT → K2 | 绿灯亮 |
| 20 | RED → K2 | 红灯亮 |
| 21 | BUZZER → K2 | 蜂鸣器响 |
| 22 | DOOR → K2 | 舵机转 90°（开门） |
| 23 | 全部再按一遍 K2 | 全部关闭 |
| 24 | MODE → K2 | 切回 AUTO，恢复自动控制 |


## 五、阈值设置

| # | 操作 | 预期 |
|---|------|------|
| 25 | 翻到 THRESHOLD → SMOKE → K2 | 烟雾阈值 +100 循环（500~4000） |
| 26 | WATER → K2 | 水浸阈值 +100 循环 |
| 27 | TEMP → K2 | 温度阈值 +1 循环（1~99） |
| 28 | MUTE → K2 | 消音 ON/OFF |


## 六、导航

| # | 操作 | 预期 |
|---|------|------|
| 29 | 子页中连续 K1 到底 | 光标下移 → 超出尾项 → 回首页 |
| 30 | 首页 K1 | 进手动页 → 再 K1 经阈值→布防→回首页 |


## 七、掉电保存验证

| # | 操作 | 预期 |
|---|------|------|
| 31 | 调一组阈值 + ARM + MUTE，去 SAVE | 保存成功 |
| 32 | 断电 5 秒 → 重新上电 | 阈值/布防/消音/模式全部恢复 |


## 四页菜单速查

```
           ┌─────────────┐
  K1/K2 ──→│  MANUAL     │  手动开关 6 路执行器 + 自动/手动切换
           ├─────────────┤
    K1 ───→│  THRESHOLD  │  烟雾/水浸/温度阈值 + 消音
           ├─────────────┤
    K1 ───→│  SECURITY   │  ARM 布防 / DISARM 撤防 / SAVE 保存
           ├─────────────┤
    K1 ───→│  STATUS     │  回到首页
           └─────────────┘
```

---

K1(PB1)=翻页/光标下移 | K2(PB11)=确认/切换 | 自动↔手动：MANUAL页选MODE

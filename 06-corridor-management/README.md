# STM32 楼道安全监测与控制系统

更新时间：2026-09-18

本工程使用 STM32F103C8T6，实现楼道环境监测、自动照明、风扇排风、声光报警和手动控制。

工程文件：`Project.uvprojx`
主程序：`User/main.c`

## 一、当前引脚总表

| 功能 | 模块端子 | STM32 引脚 | 类型 | 当前逻辑 |
|---|---|---:|---|---|
| 一氧化碳模拟量 | MQ-7 AO | PA0 / ADC1_CH0 | ADC 输入 | 读取 0~4095 原始值 |
| 光照模拟量 | 光敏 AO | PA1 / ADC1_CH1 | ADC 输入 | 数值大于等于 2000 判定为暗 |
| 烟雾模拟量 | MQ-2 AO | PA2 / ADC1_CH2 | ADC 输入 | 读取 0~4095 原始值 |
| 人体检测 | 红外对射 DO | PB10 | 数字输入 | 低电平判定为有人/被遮挡 |
| 震动检测 | SW-420 DO | PB11 | 数字输入 | 低电平判定为震动 |
| 风扇继电器 | 继电器 IN | PA9 | 数字输出 | 高电平开启 |
| LED | LED 正极或模块 IN | PB12 | 数字输出 | 高电平开启 |
| 蜂鸣器 | 蜂鸣器 SIG/I/O | PB13 | 数字输出 | 低电平开启 |
| OLED 时钟 | OLED SCL | PB8 | 软件 I2C | 3.3V 逻辑 |
| OLED 数据 | OLED SDA | PB9 | 软件 I2C | 3.3V 逻辑 |
| 翻页按键 | 按键一端 | PA5 | 上拉输入 | 按下接地 |
| 确认按键 | 按键一端 | PA7 | 上拉输入 | 按下接地 |

注意：当前 MQ-2 使用的是模拟输出 AO，接 PA2。PB0 已不再作为烟雾输入使用。

## 二、电源和共地

### 推荐供电结构

```text
5V 稳定电源
├── STM32 开发板 5V/VIN 输入（按开发板丝印接）
├── MQ-2 加热供电
├── MQ-7 加热供电
├── 继电器模块 VCC
└── 风扇电源（按风扇额定电压供电）

STM32 板载 3.3V
├── OLED VCC
├── 红外对射模块 VCC
├── SW-420 模块 VCC
├── LED 逻辑电路
└── 蜂鸣器模块 VCC（仅当模块支持 3.3V）
```

所有模块的 `GND` 必须与 STM32 的 `GND` 连接在一起。没有共地时，GPIO 和 ADC 电平可能完全不可靠。

不要使用 STM32 GPIO 给风扇、MQ 加热丝或继电器线圈供电。GPIO 只负责输出控制信号。

风扇启动和继电器吸合会造成电源波动。建议风扇/继电器与单片机使用稳定电源，并在电源入口附近增加滤波电容。若风扇和单片机使用不同电源，也必须连接信号参考地；大功率负载需要单独的驱动和保护。

## 三、模拟量模块接线

### 1. MQ-7 一氧化碳模块

```text
MQ-7 VCC  ->  按模块规格供电，通常为 5V
MQ-7 GND  ->  STM32 GND
MQ-7 AO   ->  PA0 / ADC1_CH0
```

### 2. MQ-2 烟雾模块

```text
MQ-2 VCC  ->  按模块规格供电，通常为 5V
MQ-2 GND  ->  STM32 GND
MQ-2 AO   ->  PA2 / ADC1_CH2
```

### 3. 模拟输出的过压保护

STM32F103 的 ADC 输入不能超过 3.3V。很多 MQ-2、MQ-7 模块使用 5V 供电，AO 可能超过 3.3V，不能未经确认直接接 PA0 或 PA2。

建议使用分压：

```text
模块 AO ---- 10kΩ ----+---- STM32 ADC 引脚
                      |
                     20kΩ
                      |
                     GND
```

10kΩ 位于 AO 和 ADC 之间，20kΩ 位于 ADC 和 GND 之间。5V 输入经过该分压后约为 3.33V。分压电阻的实际阻值可以使用同等比例的阻值，但必须保证 ADC 端最高电压不超过 3.3V。

如果模块由 3.3V 供电且已经确认 AO 不会超过 3.3V，可以将 AO 直接接 ADC，但仍建议先用万用表测量 AO。

当前 OLED 显示的是 MQ-7 和 MQ-2 的 ADC 原始值 `0~4095`，不是经过标定的 ppm 浓度。MQ 传感器需要预热，刚上电时数值变化较大属于正常现象。

### 4. 光照模块

当前代码需要光敏模块的模拟输出 AO：

```text
光敏模块 VCC  ->  3.3V
光敏模块 GND  ->  STM32 GND
光敏模块 AO   ->  PA1 / ADC1_CH1
```

如果手上的光敏模块只有 `VCC、GND、DO` 三个引脚而没有 AO，当前代码不能读取连续光照数值，需要更换带 AO 的模块或重新改为数字输入方案。

当前程序默认：光照 ADC 值大于等于 `2000` 时判定为暗。实际阈值需要根据 OLED 显示的现场数值调整。

## 四、数字传感器接线

### 1. 红外对射人体检测模块

```text
红外模块 VCC  ->  3.3V
红外模块 GND  ->  STM32 GND
红外模块 DO   ->  PB10
```

当前代码假定红外光束被遮挡时 `DO = 0`，也就是低电平表示有人。如果模块遮挡时输出高电平，需要修改 `SafetyIO.h` 中的：

```c
#define SAFETY_BEAM_BLOCKED_LEVEL Bit_RESET
```

改成：

```c
#define SAFETY_BEAM_BLOCKED_LEVEL Bit_SET
```

### 2. SW-420 震动模块

```text
SW-420 VCC  ->  3.3V
SW-420 GND  ->  STM32 GND
SW-420 DO   ->  PB11
```

当前代码假定震动时 `DO = 0`。如果模块震动时输出高电平，需要将：

```c
#define SAFETY_VIBRATION_ACTIVE_LEVEL Bit_RESET
```

改成：

```c
#define SAFETY_VIBRATION_ACTIVE_LEVEL Bit_SET
```

先调节 SW-420 模块上的电位器，使模块指示灯在敲击时能够变化，再观察 OLED 的震动状态。

## 五、OLED 接线

当前使用软件 I2C：

```text
OLED VCC  ->  3.3V
OLED GND  ->  STM32 GND
OLED SCL  ->  PB8
OLED SDA  ->  PB9
```

OLED 供电和信号建议使用 3.3V 逻辑。不要把 5V 逻辑直接送到 STM32 的 GPIO。

## 六、按键接线

两个按键都采用“按下接地”的接法，程序使用 STM32 内部上拉：

```text
PA5 ---- 按键 ---- GND    翻页
PA7 ---- 按键 ---- GND    确认/切换
```

不要给 PA5、PA7 外接 5V。按键松开时为高电平，按下时为低电平。

## 七、输出接线

### 1. 风扇继电器

继电器模块控制端：

```text
继电器 VCC  ->  按模块规格供电，常见为 5V
继电器 GND  ->  STM32 GND
继电器 IN   ->  PA9
```

当前代码为高电平开启。如果继电器模块是低电平触发，需要将 `SafetyIO.h` 中：

```c
#define SAFETY_FAN_ACTIVE_LEVEL Bit_SET
```

改成：

```c
#define SAFETY_FAN_ACTIVE_LEVEL Bit_RESET
```

风扇负载侧建议使用常开触点 `COM` 和 `NO`，实现上电默认关闭：

```text
风扇电源正极 -> 继电器 COM
继电器 NO    -> 风扇正极
风扇负极     -> 风扇电源负极
```

如果使用直流风扇，风扇电源电压必须与风扇额定电压一致。不要把风扇直接接到 PA9，也不要让单片机 GPIO 承担风扇电流。

涉及市电时不能直接在面包板上裸接，必须使用带外壳、保险和安全隔离的继电器模块，并由具备资质人员处理。

### 2. LED

普通单色 LED 建议串联限流电阻：

```text
PB12 ---- 220Ω~1kΩ ---- LED 正极
LED 负极 ---------------- GND
```

当前代码为高电平点亮。如果使用三针 LED 模块，模块的 `IN/S` 接 PB12，`VCC/GND` 按模块规格连接；若模块为低电平触发，需要修改：

```c
#define SAFETY_LED_ACTIVE_LEVEL Bit_SET
```

为：

```c
#define SAFETY_LED_ACTIVE_LEVEL Bit_RESET
```

### 3. 三针有源蜂鸣器模块

当前蜂鸣器控制引脚已经从 PB14 改为 PB13：

```text
蜂鸣器 VCC      ->  3.3V（确认模块支持 3.3V）
蜂鸣器 GND      ->  STM32 GND
蜂鸣器 SIG/I/O  ->  PB13
```

当前代码为低电平触发：

```text
PB13 = 0V       蜂鸣器开启
PB13 = 3.3V     蜂鸣器关闭
```

如果蜂鸣器模块必须使用 5V，不能默认将 5V 信号返回 STM32。应确认模块的 SIG 输入兼容 3.3V，并保证模块输出不会把 PB13 拉到 5V。若蜂鸣器电流较大，应使用三极管或 MOSFET 驱动，不要直接由 GPIO 带载。

本程序按有源蜂鸣器模块处理，只输出高低电平。如果是无源蜂鸣器，需要增加 PWM 方波驱动，当前固定电平不一定能发声。

## 八、自动控制逻辑

自动模式下：

```text
一氧化碳 ADC >= 2000       -> PA9 风扇开启
光照 ADC >= 2000 且有人     -> PB12 LED 开启
MQ-2 烟雾 ADC >= 2000       -> PB13 蜂鸣器开启
检测到震动                  -> PB13 蜂鸣器开启
```

其中：

- `PA0` 是一氧化碳原始 ADC 值
- `PA1` 是光照原始 ADC 值
- `PA2` 是 MQ-2 烟雾原始 ADC 值
- 红外对射被遮挡时认为有人
- 烟雾和震动报警目前没有长时间锁存，输入条件消失后输出可能关闭

阈值定义在：

```text
Hardware/SafetyControl.h
```

当前阈值：

```c
#define SAFETY_CO_FAN_ON_RAW 2000U
#define SAFETY_LIGHT_DARK_RAW 2000U
#define SAFETY_SMOKE_ALARM_RAW 2000U
```

这些是 ADC 原始值阈值，不是经过传感器标定的气体浓度标准值。

## 九、菜单操作

### 自动模式页面

按 `PA5` 在以下页面循环：

```text
第一页：传感器数据
第二页：灯光、风扇、蜂鸣器状态
第三页：自动/手动模式
```

在模式页面按 `PA7` 切换到手动模式，并进入手动风扇页面。

### 手动模式页面

按 `PA5` 循环：

```text
手动风扇
手动灯光
手动蜂鸣器
传感器页面
```

在当前手动控制页面按 `PA7` 切换对应输出。

蜂鸣器页面底部的 `PB13:0/1` 用于显示 PB13 当前输出锁存值：

```text
PB13:0 -> GPIO 输出低电平，按当前接线应触发蜂鸣器
PB13:1 -> GPIO 输出高电平，按当前接线应关闭蜂鸣器
```

## 十、首次上电测试顺序

1. 先断开风扇负载，只连接 STM32、OLED 和传感器。
2. 检查所有模块 GND 是否共地。
3. 确认 MQ-2 AO 接 PA2，MQ-7 AO 接 PA0，光敏 AO 接 PA1。
4. 用万用表确认 PA0、PA1、PA2 的最高电压不超过 3.3V。
5. 上电后等待 MQ-2、MQ-7 预热，观察 ADC 原始值是否稳定。
6. 进入自动模式，遮挡红外对射并遮光，检查 PB12 LED 是否点亮。
7. 进入手动风扇页面，确认 PA9 能控制继电器。
8. 进入手动蜂鸣器页面，按 PA7 打开，测量 PB13 应接近 0V。
9. 最后再接入风扇负载，并使用独立、稳定的风扇电源。
10. 记录正常环境下的三路 ADC 值，再根据实测值调整三个阈值。

## 十一、常见故障排查

### OLED 正常但传感器数值跳动

优先检查 MQ 模块加热供电、ADC 输入是否过压、模块和 STM32 是否共地，以及风扇/继电器是否与单片机共用导致电源压降。

### LED 自动不亮

必须同时满足：

```text
自动模式
红外对射检测到有人
光照 ADC >= 2000
```

如果光线越暗数值越小，需要反转 `SAFETY_LIGHT_DARK_RAW` 的判断方向。

### 蜂鸣器不响

检查当前信号线是否接的是 `PB13` 而不是旧引脚 PB14；手动蜂鸣器页面显示“开”时，PB13 应为低电平。还要确认蜂鸣器是有源模块、VCC/GND 没接反并且模块支持当前供电电压。

### MQ-2 没有烟雾数值

当前必须使用 `AO -> PA2`。如果只接了 `DO`，程序无法显示连续烟雾 ADC 值。

### 继电器动作相反

说明继电器模块可能是低电平触发。修改 `Hardware/SafetyIO.h` 中的 `SAFETY_FAN_ACTIVE_LEVEL`。

## 十二、当前项目边界

当前版本实现的是楼道安全监测项目：一氧化碳、光照、烟雾、人体检测、震动检测，以及灯光、风扇、蜂鸣器控制。

当前版本不包含：

- MQ-7/MQ-2 的严格 ppm 标定
- 震动报警长时间锁存
- 传感器故障诊断
- 无人十分钟断电逻辑
- 蜂鸣器无源 PWM 发声

上述功能如果需要，应在硬件联调稳定后再扩展。
